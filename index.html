1. يعني إيه Programming؟

الكمبيوتر سريع جدًا، لكنه مش بيفكر من نفسه. لازم تقوله: اعمل إيه؟ وإمتى؟ وبأي ترتيب؟

البرمجة (Programming): فن كتابة تعليمات مرتبة بلغة يفهمها الحاسوب، لينفذها ويحل بها مشكلة معينة.

2. يعني إيه Algorithm و Program؟

المصطلحالمعنىمثال
Problemالمشكلةعايز أعرف الطالب ناجح ولا راسب
Algorithmخطوات حل المشكلةاقرأ الدرجة → لو ≥ 50 → ناجح
Programتحويل الخوارزمية لكودكتابة الكود بلغة Python
⭐ تركة امتحان لو السؤال قال "مجموعة خطوات مرتبة لحل مشكلة" → الإجابة: Algorithm. لو قال "تعليمات مكتوبة بلغة برمجة" → الإجابة: Program.

6. المتغيرات (Variables)

المتغير: مكان باسم لتخزين قيمة. علامة = معناها إسناد (Assignment) مش مقارنة.

قواعد التسمية:

  • لا يبدأ برقم — ❌ 1age / ✅ age1
  • لا توجد مسافات — ❌ student name / ✅ student_name
  • _ مسموح — ✅ student_name
  • Python حساسة لحالة الأحرف — age ≠ Age
  • snake_case: أفضل أسلوب للتسمية
score = 50 print(score) # 50 score = 80 print(score) # 80

Decision Making

أهداف المحاضرة

  • فهم if / else / elif
  • الشروط المتداخلة (Nested if)
  • دمج الشروط بـ and / or / not
  • بناء نظام تسجيل دخول

1. يعني إيه Decision Making؟

في حياتك بتاخد قرارات مبنية على شروط. الكمبيوتر كمان محتاج ياخد قرارات. الأداة هي if.

Decision Making: قدرة البرنامج على تنفيذ كود معين أو عدم تنفيذه بناءً على تحقق شرط معين.

2. if — الشرط البسيط

الشكل العام:

if condition: # الكود
age = int(input("عمرك: ")) if age >= 18: print("يمكنك التصويت")
⚠️ تركة مهمة الإزاحة (4 مسافات) إجبارية. لو نسيتها → IndentationError.

3. if / else

grade = int(input("درجتك: ")) if grade >= 50: print("ناجح 🎉") else: print("راسب 😢")

4. elif — أكتر من خيار

g = int(input("الدرجة: ")) if g >= 90: print("ممتاز A") elif g >= 80: print("جيد جداً B") elif g >= 70: print("جيد C") elif g >= 60: print("مقبول D") else: print("راسب F")
⭐ تركة بايثون تفحص الشروط بالترتيب من فوق لتحت، وأول شرط يتحقق ينفذ ويخرج.

5. Nested if — الشروط المتداخلة

age = int(input("العمر: ")) if age >= 18: id = input("هل معك بطاقة؟ (y/n) ") if id == "y": print("مسموح بالدخول") else: print("يجب إحضار البطاقة") else: print("غير مسموح: أقل من 18")

6. دمج الشروط بالمنطق

t = int(input("الحرارة: ")) r = input("يوجد مطر؟ (y/n) ") if t > 30 and r == "n": print("اذهب للسياحة") elif t < 15 or r == "y": print("ابق في البيت") else: print("الجو عادي")

7. مشروع: نظام تسجيل دخول

USER = "ali" PASS = "1234" u = input("اسم المستخدم: ") p = input("كلمة السر: ") if u == USER and p == PASS: print("مرحباً بك يا", u) elif u == USER: print("كلمة السر خاطئة") else: print("المستخدم غير موجود")

  • نطاق المتغير (Scope)

1. يعني إيه Function؟

Function: كتلة كود مستقلة، لها اسم، بتنفذ مهمة معينة، وممكن تستقبل بيانات وترجع نتيجة.

ليه بنستخدمها؟

  • إعادة استخدام الكود (من غير تكرار)
  • تنظيم البرنامج
  • سهولة التصحيح
  • سهولة القراءة

2. تعريف الدالة (def)

def greet(): print("Hello, World!") greet() # استدعاء الدالة
⚠️ تركة لو عرّفت دالة ومش استدعيتها → مش هتتنفذ.

3. البارامترات والوسائط

def greet(name): print("Hello,", name) greet("Ali") # Hello, Ali greet("Sara") # Hello, Sara

4. return — القيمة المرجعة

def square(x): return x * x r = square(5) print(r) # 25 print(square(3) + square(4)) # 25

🚨 تركة لو الدالة مش فيها return → بترجع None تلقائياً.

5. القيم الافتراضية

def greet(name="صديق"): print("Hello,", name) greet() # Hello, صديق greet("Ahmed") # Hello, Ahmed

6. إرجاع أكثر من قيمة

def min_max(nums): return min(nums), max(nums) lo, hi = min_max([3, 1, 5, 2]) print(lo) # 1 print(hi) # 5

7. النطاق (Scope)

def my_func(): x = 10 print(x) my_func() # 10 print(x) # ❌ NameError — x محلي
💡 معلومة المتغيرات جوه الدالة بتكون محلية (Local) — مش بتأثر على بره الدالة.

def max_of_two(a, b):
    if a > b:
        return a
    else:
        return b

print(max_of_two(10, 5))   # 10

def is_even(n):

اكتب دالة تاخد قائمة وترجع مجموعها.
def total(nums):
    s = 0
    for n in nums:
        s += n
    return s

print(total([1, 2, 3, 4]))   # 10

اكتب دالة تتحقق إذا كان النص متناظر (Palindrome).
def is_palindrome(text):
    return text == text[::-1]

print(is_palindrome("madam"))   # True
print(is_palindrome("hello"))   # False
